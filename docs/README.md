# Portfolyo sitesi

Bu klasör GitHub Pages ile yayınlanan kişisel portfolyo sitesidir. Statik HTML, CSS ve JavaScript; derleme adımı yok.

- `index.html`: içerik (Türkçe)
- `main.js`: İngilizce metinler ve dil geçişi
- `layers.js`: hero animasyonu
- `style.css`: tasarım

Yerelde: `cd docs && python3 -m http.server`
